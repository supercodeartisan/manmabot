ZF
==

This is the customer portable folder. Keep the whole folder together.

First run
  1) Right-click Driver_Install_Interception.bat → Run as administrator
     Reboot if Windows asks.
  2) Start Lineage (LC.exe).
  3) Double-click ZF.bat (Administrator / UAC as prompted).
     Memory support also starts SignedDriver under Drivers\SignedDriver\.

Notes
  - Settings are stored in UserData\ next to this folder (created on first run).
  - Do not move ZF.bat / ZF.exe away from python\, Engine\, UI\, Drivers\.
  - Calibration / research tools are not included in this package.

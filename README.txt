Manmabot Version 1
==================

No Python install and no internet are required after this folder is copied.

1. Keep this folder together (do not move ManmabotV1.exe away from python\ and engine\).
2. Right-click install-interception.bat -> Run as administrator. Reboot if asked.
3. Start Lineage (LC.exe).
4. Double-click ManmabotV1.exe (Windows will ask for Administrator).
5. Memory lamp starts the signed driver (UAC). Game lamp brings the client forward.

Settings are stored in userdata\ next to this exe (created on first run).
